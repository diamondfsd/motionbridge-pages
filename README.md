# MotionBridge Pages

Public, bilingual support and privacy pages for MotionBridge.

- Technical support: <https://diamondfsd.github.io/motionbridge-pages/support.html>
- Privacy policy: <https://diamondfsd.github.io/motionbridge-pages/privacy.html>

The site is plain HTML/CSS/JavaScript and is deployed to GitHub Pages by the workflow in `.github/workflows/pages.yml`.

MotionBridge is an independent React Native app for routing motion data from supported inputs to supported cameras and gimbals.
